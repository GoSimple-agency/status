# Tezga status

Automated availability checks of the public Tezga endpoints, every 30 minutes.

Live page: **https://gosimple-agency.github.io/status/**

This table is regenerated by the [Status workflow](.github/workflows/status.yml) on each
run — it only performs public GET requests and stores the history here, with no credentials.
The first results appear after the workflow's first run.

Monitored: the website, the developer documentation and the OpenAPI specification. See
[`endpoints.json`](./endpoints.json).
